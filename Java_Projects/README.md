# Java Projects

This folder contains Java coursework projects covering object-oriented programming, algorithm analysis, recursion, sorting, and data structures. The projects are independent exercises rather than one combined application.

| Project | Summary |
| --- | --- |
| [Burrito Class and Order](Burrito%20Class%20and%20Order/) | Models burritos and customer orders using Java classes and objects. |
| [Company Employee Hierarchy](Company%20Employee%20Hierarchy/) | Represents company employees and their relationships using object-oriented classes. |
| [Complexity Analysis](Complexity%20Analysis/) | Coursework exercises focused on algorithm analysis and complexity. |
| [Doubly Linked List](Doubly%20Linked%20List/) | Implements and exercises a doubly linked list and its nodes. |
| [Hashing and Maps](Hashing%20and%20Maps/) | Applies hashing and map-based structures to contact-list exercises. |
| [Movie Ratings Binary Search Tree](Movie%20Ratings%20Binary%20Search%20Tree/) | Uses a binary search tree to organize and work with movie-rating data. |
| [Recursion](Recursion/) | Exercises recursive methods with numeric and string inputs. |
| [Sorting Algorithms](Sorting%20Algorithms/) | Includes selection sort, merge sort, and quicksort exercises. |
| [Stacks Queues and Burrito Shop](Stacks%20Queues%20and%20Burrito%20Shop/) | Implements stack and queue structures and applies them to a burrito-shop exercise. |
| [Towers of Hanoi](Towers%20of%20Hanoi/) | Explores Java implementations of the Towers of Hanoi problem. |

These are separate course projects with their own source files and instructions. Open the relevant project in an IDE or consult its included course materials; there is no shared build or run command for the entire folder.
