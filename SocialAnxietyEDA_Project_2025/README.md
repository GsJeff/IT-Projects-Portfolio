# Social Anxiety Exploratory Data Analysis

This project uses a Jupyter notebook to explore social-anxiety survey data, including possible relationships with demographics, sleep, physical activity, diet, and stress. The analysis is exploratory and describes associations; it does not establish cause and effect.

## Files

- `Social_Anxiety_EDA_GraemeJ.ipynb` — analysis notebook.
- `enhanced_anxiety_dataset_mod.csv` — dataset currently loaded by the notebook.
- `enhanced_anxiety_dataset.csv` and `enhanced_anxiety_dataset_mod2.csv` — additional dataset versions included with the project.

## Running the Notebook

Open the notebook in Jupyter from this folder. It uses Python with NumPy, pandas, Matplotlib, and Seaborn. Install any missing packages in your environment before running the cells.

## Data Source

The notebook identifies the source dataset as the [Social Anxiety Dataset on Kaggle](https://www.kaggle.com/datasets/natezhang123/social-anxiety-dataset). Refer to Kaggle's terms and the dataset's own licensing information for permitted use of the data.
