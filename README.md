## Java Projects

The Java work in this portfolio includes coursework in object-oriented design, algorithm analysis, recursion, sorting, and data structures such as linked lists, stacks, queues, maps, and binary search trees. It also includes the **Email Spam Identifier**, a Maven-based Swing application that preprocesses email text and uses a Bayes-based probability model to estimate whether messages are spam or ham. See the [Java coursework index](Java_Projects/README.md) and the [Email Spam Identifier README](EmailSpamIdentifier_Project_2026/EmailSpamDetector/README.md).
