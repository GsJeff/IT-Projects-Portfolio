## Java Projects

The portfolio's Java project is the **Email Spam Identifier**. It is a Maven-based Swing application that preprocesses email text and uses a Bayes-based probability model to classify messages as spam or ham. Its GUI presents the analysis results for the supplied test folders. See its [project README](EmailSpamIdentifier_Project_2026/EmailSpamDetector/README.md) for screenshots and run instructions.
